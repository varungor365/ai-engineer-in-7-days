## ✨ What is this?

The field of AI Engineering is moving faster than any other engineering discipline in history. If you are a traditional software engineer looking to pivot into AI, this repository is for you.

Instead of reading textbooks on linear algebra, this course focuses entirely on the **practical** skills you need to build AI applications today: Prompt Engineering, RAG, Agents, and Fine-tuning.
